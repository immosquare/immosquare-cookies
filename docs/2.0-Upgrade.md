# immosquare-cookies — migration guide from v1 to v2

Upgrading the immosquare-cookies gem from v1 to v2 changes one render parameter, replaces the whole stylesheet, and adds the automatic removal of cookies on refusal.

## Breaking changes of immosquare-cookies v2

The `link:` parameter of the consent banner is replaced by two distinct links:

```ruby
# v1
render("immosquare-cookies/consent_banner", link: "https://example.com/policy")

# v2
render("immosquare-cookies/consent_banner",
  privacy_policy_link: "https://example.com/privacy",
  cookie_policy_link: "https://example.com/cookies")
```

The banner design is a complete CSS redesign. Custom overrides may need updates.

## New in immosquare-cookies v2 — the `cookies_to_remove` parameter

```ruby
render("immosquare-cookies/consent_banner",
  cookies_to_remove: ["_ga", "_gid", "_fbp"])
```

Automatically removes specified cookies when consent is refused.
